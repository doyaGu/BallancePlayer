# BallancePlayer v0.3.9 (2026-09-24)

This release adds a built-in configuration dialog and a standalone `ConfigTool.exe`. Player opens the dialog on first launch when `Player.ini` is absent, and **Alt+C** opens it during gameplay. Saved changes take effect after restarting the game.

Other highlights:

- Multi-monitor support and improved fullscreen, screen-mode, and frame-rate handling.
- More reliable command-line parsing, configuration saving, and runtime path resolution, including flat game layouts.
- A startup prompt for an existing Player instance; forced exit is limited to the same executable path.
- Improved Visual C++ 6.0 and Virtools SDK compatibility; VC6 and MSVC 2022 builds are supported.

Extract a package into the game's `Bin` directory, or use the flat layout described in the included README. Keep the game's assets and runtime DLLs in place.
